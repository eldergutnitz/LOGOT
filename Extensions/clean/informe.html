La política corporativa permite un único asistente de terceros: GitHub Copilot. Se admite además la IA que publique Microsoft (IntelliCode, Azure MCP Server, Copilot for Azure). Todo lo demás queda denegado en policy/, incluidos los asistentes de fabricantes cuyo resto de extensiones sí están permitidas: cada uno envía código fuente a un tercero distinto.

Alcance de este análisis. Se apoya solo en el inventario: identificadores, versiones, publishers, categorías y repositorios declarados.
  • No consulta CVE ni avisos de seguridad publicados.
  • No comprueba el estado de publisher verificado ni la firma en el marketplace.
  • No analiza el código de las extensiones ni su tráfico de red.
  • «Desactualizada» es relativo a la propia flota, no a la última versión publicada.
Sirve para priorizar qué revisar, no para declarar nada seguro.
