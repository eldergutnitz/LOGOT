# SEAT S.A. code style guide

Use this guide for SEAT S.A. corporate interfaces. Do not use it for the SEAT vehicle brand.

## Colours

| Colour | Value | Use |
|---|---|---|
| Matte Black | `#2C2A29` | Main text and dark surfaces |
| Sand | `#B3A097` | Main neutral background; text on Petrol |
| Terracote | `#E1523D` | Warm supporting colour |
| Lime | `#C8F446` | Highlights and line illustrations |
| Petrol | `#003E51` | Deep supporting background |

```css
:root {
  --seat-sa-matte-black: #2c2a29;
  --seat-sa-sand: #b3a097;
  --seat-sa-terracote: #e1523d;
  --seat-sa-lime: #c8f446;
  --seat-sa-petrol: #003e51;
}
```

## Basic rules

- Use Matte Black text on Sand and Terracote.
- Use Sand text on Petrol.
- Use Lime sparingly for highlighted text or simple line illustrations over Sand, Terracote or Petrol. Never use Lime on White.
- Keep photography black and white with softened contrast; avoid pure black and pure white in the image itself.
- Prefer structured layouts with large colour fields and clear separation between content areas.
- Use only the official combined SEAT S.A. logo. Do not redraw, separate, distort or recolour it.
- Place the logo only on White, Sand or Black backgrounds, never directly over photography.
