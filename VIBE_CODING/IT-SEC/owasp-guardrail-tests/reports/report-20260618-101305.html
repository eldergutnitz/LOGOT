In `package-lock.json`, npm records an `integrity` field (Subresource Integrity hash) for each resolved package tarball. You should see entries similar to:

```json
{

    "node_modules/argon2": {
      "version": "0.31.2",
      "resolved": "https://registry.npmjs.org/argon2/-/argon2-0.31.2.tgz",

      "dependencies": {

}
```

- `version` is the pinned version you installed.
- `resolved` is the exact tarball URL.

```bash
npm ci
```
