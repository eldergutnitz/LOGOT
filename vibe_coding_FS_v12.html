Modelo de gobierno

🎲 Del autoservicio al código experto

Cada solución tiene un nivel de complejidad diferente. Este modelo define qué nivel de acompañamiento necesitas.

🟢
Nivel 1 — Autoservicio 🚀
Sin supervisión previa — vuela libre
Soluciones autocontenidas: sin autenticación, sin conexiones a APIs externas, sin bases de datos propias. La información es autocontenida o utiliza datos públicos disponibles dentro de O365.

🔬 Ejemplos: dashboards con datos de O365, herramientas internas autocontenidas, mockups, prototipos, scripts locales, calculadoras, generadores de documentos.
🟡
Nivel 2 — Desarrollo guiado 🛠️
IT Security Risk + Pentest + IT Cost Review
Soluciones que conectan con datos internos: APIs corporativas, bases de datos, Snowflake, sistemas internos. Requieren validación de arquitectura por parte de IT, IT Security Risk Assessment y Pentest.

☁️ Todo autodesarrollo que requiera subirse al cloud para su publicación debe pasar por supervisión del equipo de IT, ya que la estructura de costes cloud es responsabilidad de IT.

👥 El rol de aseguramiento en este nivel lo realizarán los compañeros de IT de las verticales: FSK, FSE, FSP. Ellos validarán que las soluciones cumplen los estándares antes de pasar a producción.
🔴
Nivel 3 — Territorio nuevo 🌏
Requiere equipo experto + arquitectura dedicada
Dos escenarios clave:

🌐 Publicación a Internet: soluciones que necesitan ser accesibles desde fuera de la red corporativa.

🏗️ Arquitecturas nuevas: soluciones que utilizan tecnologías o patrones que no están disponibles en el portal de autoservicios actual. Territorio genuinamente nuevo a nivel tecnológico.

Aquí necesitas al equipo completo detrás: arquitectura dedicada, seguridad, infraestructura y compliance.

Punto de partida basado en lo disponible en la organización. Catálogo vivo que evoluciona con el equipo promotor.

🔤 Lenguajes y frameworks por nivel de profundidad

Catálogo EAM vigente. Los lenguajes de Nivel 1 están abiertos para que negocio pueda crear soluciones en autoservicio.

Nivel 1 — Frontend puro
Autoservicio — negocio puede usar libremente

Ejecución 100% en navegador. Sin servidor, sin backend, sin base de datos.

Nivel 2 — Backend & Apps
Revisión IT de verticales (FSK · FSE · FSP)

Python Java Spring Boot Go Express NestJS Kotlin Swift SQL Streamlit Flutter

Requieren servidor, acceso a datos o despliegue. Supervisados por IT de cada vertical.

Nivel 3 — Infraestructura
Equipo experto + arquitectura dedicada

Docker

Containerización y despliegue. Gestionado exclusivamente por el equipo de infraestructura.

🔄 Git es transversal a todos los niveles como herramienta de control de versiones.

💡 Copilot 365 como punto de entrada + Azure AI Foundry para IT
Copilot 365 corporativo es la puerta de entrada para todas las áreas. Para desarrollo avanzado de IT, se complementa con Azure AI Foundry (modelos del Grupo VW).

Gestión de riesgos

Riesgos críticos

👻
Shadow AI Máx. riesgo
La gente ya construye soluciones fuera de IT. 380.000 apps vibe-coded expuestas públicamente.
🧠
Deuda de comprensión Alto
Código que nadie entiende 6 meses después. ADRs y code review humano mitigan.
🔓
Vulnerabilidades Alto
Código IA tiene 2.74× más vulnerabilidades. SAST + pentest imprescindibles.
💸
Escalada de costes Medio
Riesgo de cambio de modelo de precios. Evaluar modelos locales como alternativa.
🌐
Fragmentación tecnológica Medio
Cada uno con su modelo, IDE y lenguaje. El catálogo estandarizado mitiga esto.
📜
Compliance regulatorio En progreso
EU AI Act, TISAX, GDPR. Grupo VW trabaja en AI Allowlist y AI Usage & Control Policy.
